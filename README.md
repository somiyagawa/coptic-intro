# コプト語入門（サイード方言・教会ボハイラ方言）

静的サイトです。ビルドは不要です。

## Vercel への公開

    cd coptic-intro
    npx vercel --prod

フレームワークは "Other"、ビルドコマンドと出力ディレクトリは空欄のままにします。
GitHub にこのフォルダを push して Vercel の "Import Project" から読み込んでも同じです。

- index.html     方言の選択画面
- sahidic.html   コプト語サイード方言入門（全20課）
- bohairic.html  コプト語教会ボハイラ方言入門（全24課）
